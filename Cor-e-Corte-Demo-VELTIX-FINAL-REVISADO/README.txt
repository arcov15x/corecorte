COR & CORTE — DEMO FINAL REVISADA
Desenvolvido pela VELTIX

ABRIR NO COMPUTADOR
- Extraia o ZIP inteiro.
- Abra o arquivo index.html.
- O CSS e o JavaScript principais estão embutidos no próprio index.html, então o visual não depende de styles.css/script.js para funcionar.
- Os arquivos styles.css e script.js também ficam no pacote como cópia editável.

HOSPEDAGEM
- O arquivo index.html está na RAIZ do projeto, pronto para hospedagem estática (ex.: Netlify).
- Faça upload da PASTA extraída ou do ZIP inteiro, conforme a plataforma aceitar.

REVISÃO FEITA
- Sintaxe JavaScript
- Estrutura HTML
- CSS/responsividade
- Links internos
- Menu mobile
- Formulário/WhatsApp
- Logo sem distorção
- Acessibilidade básica
- Segurança do front-end
- Headers de segurança para Netlify (_headers)
- robots/noindex para a demo não aparecer em buscadores

SEGURANÇA
- Site estático, sem banco de dados, login, cookies, analytics ou armazenamento de dados pessoais.
- O formulário não envia dados para servidor da VELTIX: ele apenas monta uma mensagem e abre o WhatsApp.
- Links externos usam HTTPS e proteção noopener/noreferrer.
- Há CSP e headers de proteção no arquivo _headers para hospedagem compatível.

IMPORTANTE
- O endereço exato foi removido desta demo porque as referências disponíveis apresentaram endereços diferentes. A página mostra apenas Nova Prata - RS e abre uma busca pelo nome do salão.
- Os serviços e imagens são demonstrativos. Antes de publicação oficial, confirme serviços, fotos, telefone e endereço com a Cor & Corte.
